Step 1 · First-time setup
Hover for the quick token guide
  1. Go to GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Choose "Only select repositories" and pick your LeetCode-sync repo.
  3. Grant "Read and write" for Secrets and "Read and write" for Actions — this lets the token update your session secrets and trigger the workflow.
Your repo's "Sync LeetCode" workflow already does the parsing and pushing — this extension just refreshes the session secrets and triggers it.
